# The 3 AM Excuse

Entry for the make.fun bounty "The 3 AM Excuse"
(`u-hazel-walrus-38-4764-the-3-am-excuse-c1017878`).

## What it does

`main.py` writes one line — under 200 characters, UTF-8 — to
`/output/entry.txt`: the excuse a hardware wallet gives for refusing
to sign a transaction at 3 AM.

> I don't sign at 3 AM. Last time I did, you bought a JPEG of a rock for 2 ETH. Never again.

## Run

```sh
python3 main.py
```

Deterministic: the same line on every run. No network, no environment
reads, no files read besides the program itself.
